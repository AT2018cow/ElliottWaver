# 路线图 A–G 修复复验

对应 [EW-R01–R09 独立验收](2026-11-19-roadmap-independent-acceptance.md)。在 DeepSeek 的工作区实现上修正收盘摘要、历史回放、概率研究和核销。

| 问题 | 修复与复验 |
| --- | --- |
| EW-R01 决策时模型 | 默认按决策截止时间选择已获批模型，检查特征版本、适用范围和发布证据。显式指定模型的旧数据重算单列为回顾性。复验了未来批准前拒用、批准后可用、撤回和文件缺失后的回退。 |
| EW-R02 分段隔离 | 评估清单与协议、数据文件、引擎版本和计算配置对账。训练使用预定到期日清除跨段行，按市场、证券类别、周期、feed 和复权口径各自拟合。合成分段用例验证按 13／14／12 行保留，早期文件缺清单时拒绝训练。 |
| EW-R03 决策网格和事件 | 缺失交易日保留为不可分析。以交易会话锁定日、周到期日，缺周不顺延。收盘类只需要到期价。触价类按顺序扫描，明确信号可提前结算。短窗口和完整窗口统一复权基准。 |
| EW-R04 核销 | 保留发行时收盘、ATR、预定会话、复权参考、边界和候选 ID。修订前缀而保持未来行情相同，结果和修订号不变。单独修订未来价格时保留最初观察并写新结果。 |
| EW-R05 历史校验 | 历史查询、前次对照和核销复用报告校验，校验清单、文件和业务身份。改写价格后历史读取和结算都拒绝。延续、备选升主和结构变化分别识别，前次条件命中单列。已实测旧版 1.0 报告可读取。 |
| EW-R06 盲标坐标 | 图形使用发布时准备过的行情。茅台 2025-10-17 的日线盲标收盘恢复到 1455.00，与报告相同。没有指定到期价时保留缺失或截尾状态。 |
| EW-R07 输出格式 | 摘要业务 ID 与文件表示分开，允许 Markdown、HTML 和不同渲染器共存。同一表示并发发布时验证并复用完整产物。 |
| EW-R08 候选特征 | 方向权重从全部合格候选计算，加入周线背景与缺测标识。Top-K 只控制展示。候选事件按 ID 绑定特征、概率和核销，缺少规定条件时标记事件未定义。 |
| EW-R09 锚点解释 | 选窗保留手动起点、回退、背景高低点和确认时刻。备用窗口展示实际采用的起点。 |

## 结果核对

真实冻结快照复验覆盖 600519.SH、300750.SZ、000001.SH、000300.SH。四组日线及由同源派生的四组周线都与正式引擎独立结果的摘要一致。同一摘要改用 Markdown 导出后业务身份一致，产物互相独立。三角形的六条正式入口复验通过，包含两条茅台复权反例。

概率训练模型格式升级到 1.2。既有 2023–2025 年扩大样本结果仍可作为探索记录查看。新的四标的复验单列 2026-04-01 至 2026-09-30 留出，以个股和指数各自建模检查数据流。每组仅两个标的，默认注册表继续无批准模型。所有修复后的发行概率仍要求独立留出证据。[复验协议](../protocols/roadmap-repair-2026-heldout-smoke.json)

- 全量测试 262 项通过，42 条告警来自既有第三方日期依赖。Ruff lint、格式、`pip check` 和差异检查通过。
- 四标的回放共 768 个可分析决策、10,986 条事件。后处理按决策 ID 对账，并将个股和指数拆成两个独立品种组。每组四项事件均为 `INSUFFICIENT_EVIDENCE`。
