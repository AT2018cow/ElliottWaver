# 多浪级波浪引擎修复复验

本轮针对独立验收发现修复。默认 `classic_v4` 按原 `0.2.1` 规则运行，日周增强通过 `config.advanced.example.yaml` 显式启用。增强结果使用 `hierarchical-rules-v2` 标识，配置名称仍为 `hierarchical_v1`。 [初次独立验收](2026-11-20-wave-engine-codex-review.md)

| 项目 | 修复与复验 |
| --- | --- |
| 默认模式 | 隔离增强亚型、候选聚合和多窗复核。用原本地 `0.2.1` 源码包复跑茅台和 AAPL 的冻结快照，默认 `analyze`、`brief` 的业务字段和摘要全部一致。 |
| WE-1 逐腿认证 | 检查 bar 来源、可用时刻、确认状态及严格端点。深度 0 的结构无已验证层，深度 1 输出每条通过的子节点，深度 2 按所有必要子节点的已验证深度汇总。确定违反硬规则的候选在排名前退出。回归覆盖右端点晚于截止、内部进行中拐点和 `SEED`。 |
| WE-2 日周关系 | 以父腿终点命名。对照交易日历、周极值、原始 OHLC 与复权桥接。进行中的周线第 4 浪与下行日线锯齿可建立 `PROVISIONAL` 关系。等价极值与无法核实的历史端点保留待确认。已验价格转换、缺记录、未知价格基准和不允许的子模板用独立构造的日周用例验证。 |
| WE-3 亚型 | 阻挡型独立核对 B–D 的一个 tick 容差。截短第五浪须有完整的第五腿驱动证据。双重三浪走独立几何、内部模板和位置校验，浅 X、Y 未超过 W 的正例通过。平台三种、引导与终结楔形均有带真实内部结构的合成正例。原斜边三角形、单调 W5 和缺 `3-3-5` 的顺势平台保留为反例。 |
| WE-4 搜索与选窗 | 增强搜索按尺度、锚点轮转，同一周期的枚举、认证与备选窗口共用预算。去重同时比较亚型、浪级和失效条件。换窗主结论考虑全部参与窗口。基准脚本按单次分析和完整摘要计时。 |
| WE-5 回放与报告 | 条件触发检查发行时间、条件生效时间、bar 可用时刻及价格坐标。缺口之后记录观察证据，同根多条件按原有事件歧义口径。结构回放与 `brief` 使用同一构造和比较流程。HTML、Markdown 与终端输出子浪及日周证据。 |

依赖下限与序列化能力同步为 `pydantic>=2.12,<3`。复验使用锁定的 2.14.0。旧报告以原始 JSON 核验业务摘要，继续读取已发布版本。

## 冻结复验

- 按原 `0.2.1` 的同一份输入与配置对照默认分析输出。
- 对茅台和 AAPL 各三个截止点比较完整冻结快照与物理前缀。日线候选、周线候选以及日周关系逐项一致。此检查对应冻结数据回放。
- 用正式评估脚本复跑 AAPL 的五个冻结决策。五项均为 `OK`，保留 `FROZEN_DATA_REPLAY`、日周关系及相邻决策事件，清单记录增强规则版本。
- 在临时目录构建并安装 wheel，使用 `000016.SH` 和 `AAPL` 的冻结快照各跑一次 `analyze` 和 `brief`。四项均为 `OK`，摘要校验通过，HTML、Markdown 和终端均已核查日周证据。
- 使用 `tests/test_variant_fixtures_end_to_end.py` 运行带子浪的端到端正例与原误报样例。`tests/test_hierarchical_engine.py` 独立验证真实日周聚合、父浪编号、搜索预算及确认状态。
- `tests/test_decision_comparison.py` 验证生效前行情、首次触达的交易日缺口和条件事件保留。
- 14 个确认拐点的独立穷举给出 50 个经典几何候选。预算充足时两种模式都找到全部 50 个，增强搜索另找到 16 个新规则几何候选。
- 全量 `423 passed`。Ruff 检查、格式检查、`git diff --check` 和 `pip check` 通过。

## 摘要延迟

比较原 `0.2.1` 默认模式与这次修复后的 `config.advanced.example.yaml`。沪深使用 `600519.SH`、`000016.SH`，美股使用 `AAPL`、`SPY`。各取 2026-10-29 至 2026-11-18 的 15 个交易会话，预热后各跑三轮，每市场每模式有 90 次计时。每次 `build_brief` 单独计时，包含行情整理、日周关联和换窗，快照读取与渲染在计时之外。

| 市场 | 模式 | 单周期分析 p50 / p95 | 完整摘要 p50 / p95 | 摘要 p95 相对基线 |
| --- | --- | ---: | ---: | ---: |
| 沪深 | 原 `0.2.1` | 287 / 865 ms | 815 / 1,851 ms | 1.00× |
| 沪深 | 修复后增强模式 | 866 / 3,542 ms | 2,155 / 6,179 ms | 3.34× |
| 美股 | 原 `0.2.1` | 263 / 534 ms | 757 / 1,477 ms | 1.00× |
| 美股 | 修复后增强模式 | 789 / 2,104 ms | 1,676 / 3,451 ms | 2.34× |

每组 30 个决策均可分析，单周期结果未出现 `SEARCH_LIMITED`。两市场的摘要 p95 都超过默认切换的两倍门槛。因此日用仍默认 `classic_v4`，日周增强通过 `--config config.advanced.example.yaml` 启用。仓库的成对基准脚本另有小样本冒烟复验，正确标记 `INSUFFICIENT_SAMPLE`。 [基准脚本](../../scripts/benchmark_wave_engine.py)
