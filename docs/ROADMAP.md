# EliotBot 长期产品路线图

规划基线为 2026-11-18 的 `98e287b`（`subwave-v6`）。产品目标是让用户在收盘后输入一个个股或指数代码，就能看懂当前可能处于哪一浪、接下来的几种走法、哪些价格会改变判断，以及这些判断以往有多可靠。先交付日常可用的分析工具，再按市场和预测期限逐项开放经过验证的概率。

## 今天已经能用什么

沪深个股与已接入的沪深京指数可直接分析日线或周线。当前一次运行一个主周期，引擎从已确认的背景拐点选择多个分析起点，找不到合格起点时回退到最多 252 根 K 线。已有推动、ABC 锯齿、平台、三角形、楔形和双锯齿六类候选，内部子浪的认证程度会随模板和数据变化。报告已有浪标、相对权重、条件价、目标区及可离线打开的图表。统计概率字段仍为空。[使用手册](USER_GUIDE.md) · [实现与验收状态](IMPLEMENTATION_STATUS.md)

```bash
.venv/bin/eliot analyze 600519                  # 贵州茅台，日线
.venv/bin/eliot analyze 000300.SH --timeframe 1w  # 沪深300，周线
```

在 2026-11-16 的贵州茅台冻结日线报告中，普通推动第 3 浪和楔形第 3 浪各占约 23.4% 的候选权重，两者都指向下一段向上。一份报告应同时说明这两种解释各有何依据，以及未来几天的价格怎样才能区分它们。 三角形继续采用经典 A 组，B 组保留作研究对照。过去 1,694 个时点只产生 8 个两组共有的去重信号，留作结构回归用例。[三角形规则与复验](reviews/2026-11-18-cn-triangle-classic-v6.md)

## 一份完整报告应该回答什么

| 用户的问题 | 产品约定 |
| --- | --- |
| 从哪天开始看，为什么？ | 默认为日线判当前阶段、最近一个已完成的周线提供背景。按历史覆盖、已确认转折和可辨认的浪段选择主窗口，并保留另一合理起点做敏感性检查。显示起止日、根数、选取或回退理由及换窗口后结论是否改变。允许手动锁定锚点。分析起点与向未来预测的期限分别设置。 |
| 当前可能是哪一浪？ | 展示主选及至多两个有实质差异的备选。标明浪级、阶段、已确认点、暂定点、支持和冲突证据。日周线可以同时成立的父子结构分开展示。同级计数相互竞争时说明是哪处转折产生了分歧。一个候选或没有合格候选也能生成有明确结论的报告。 |
| 明天开始观察什么？ | 每个候选给出下一段方向、确认条件、失效或阶段结束条件、目标区和适用期限。下次收盘标明哪条线被触发、哪个备选升为首选，以及变化来自新 K 线还是行情修订。 |
| 这些判断有多可靠？ | 分开展示结构支持度、候选在期限内得到价格确认的概率、标的本身的短期走势概率。每个已发布概率都附事件定义、期限、适用市场、样本量、校准日期与历史误差。未达门槛时，报告仍给出剧本、条件与证据状态。 |

### 两种概率怎样定义和结算

**浪型。** 今天可比较同级候选的证据和相对权重。第一项可验证的候选概率定义为“自今天收盘起，未来 20 个交易日内，这个候选先触发预定确认线，且此前未触发失效线”。窗口到期仍未确认计为未中，同根双触及、缺失及未到期各自单列。缺少任一必要条件的候选显示事件未定义。多个候选可以同时得到确认，各自概率无需合计 100%。

如果还希望看到“这段结构属于推动浪或楔形的概率”，需另建标注集。固定同一浪级、端点范围和判读时点，由两位独立标注者在隐藏模型结果与未来价格后判读，允许多种合理解释或无法判定。按浪型分别检验模型预测与盲标的一致程度。通过的类别可发布“与该标注口径一致的概率”，并披露标注者间的一致率。分歧大的类别继续显示候选支持度。

**短期走势。** 第一项预测取未来 **5 个交易日收盘**，第二项取 **20 个交易日收盘**，逐期限验证。拟以决策日收盘价为中心、上下各 1 个当时的日线 ATR(14) 为边界。到期收盘高于上界为“上涨”，低于下界为“下跌”，含边界的中间区间为“区间内”。三类互斥，完整数据下概率合计 100%。例如先突破上界、到期又回到区间内，该次结算为“区间内”。途中先触及目标还是失效线另行统计。未来个股价格统一换算到决策日复权基准，指数用原始点位。阈值在开发期冻结。

走势模型可用全部候选的方向分歧、证据质量、波动和周线背景作输入。将“波浪特征加价格信息”与“只用价格、波动信息”在同一批时点比较，才能判断波浪分析给方向预测增加了多少信息。

这两项新预测各有自己的事件编号。已归档三角形实验继续沿用其日线 20 日、周线 8 周的途中触价规则。如重开 A/B 比较，仍按原协议的 50 个去重分歧信号和效应门槛判定。[三角形实验协议](reviews/2026-11-18-cn-triangle-experiment-protocol.md)

## 交付顺序和完成标准

时间从开始实施算起，按一名开发者、现有沪深数据链路可用估算。研究样本成熟和外部数据授权另计。各行的退出条件决定能发布哪些能力。

| 阶段与预计时间 | 需要做的工作 | 到什么状态就交付 |
| --- | --- | --- |
| **日常可用版 · 第 1 周** | 在现有 CLI 和 HTML 上做一页收盘摘要，补齐选窗理由、主备剧本的分歧点和下一条观察条件。同时从首日留存带时间戳的输入快照和原始判断。 | 从空报告目录输入代码，无需指定锚点即可完成。用两只沪深个股和两个指数，从终端到图表逐项核对日期、浪标及条件价。对无合格候选、数据不足、没有合法目标分别给出可读结果。达到这里就交给用户日常使用。 |
| **多周期与连续跟踪 · 第 2–3 周** | 一次请求生成日线主图和完整周线背景。比较默认与备选窗口，标注长短周期分歧。给同一版本的相邻收盘报告增加变更说明，并支持按日期取回旧报告。 | 新股短历史、震荡中多个合理起点、日周方向相反、除权和未完成周都有验收样本。输入同一冻结前缀可复现窗口、候选及关键价。历史报告可还原当时显示的判断。 |
| **全引擎评估 · 第 4–6 周** | 通用离线入口复用正式分析服务。先对账上证指数与茅台，再按沪深主板、科创板、创业板分层取约 30 只个股，另列四个代表指数。建决策表、事件表、排除原因及校验清单，按浪型统计覆盖率、确认延迟、首选切换率、目标与失效次序。 | 每个预定时点均能对账，分母为零显示空值。冻结输入与固定预热起点下，截掉未来行情后，已确认拐点和当期决策一致。两条茅台复权反例、五平台反例和首选切换案例通过。输出可复算的基准报告和最常见失败清单。 |
| **概率试用与有条件发布 · 第 7–12 周** | 先完成 5 日三分类的训练、独立校准及留出检验。沿用同一流程做 20 日三分类和候选确认概率。将成功、失败、区间内、歧义、停牌及截尾按对应事件记账。在正常收盘流程中记录预测、到期核销。 | 每个“市场或品种组 × 期限 × 事件”独立过下述门槛。通过哪项就发布哪项。未通过的交付评估报告，界面标出样本不足或验证未通过。第 12 周交付明确结论，概率发布日期取决于证据。 |
| **稳定版与范围收口 · 第 3–6 个月** | 根据失败清单只优先补最影响覆盖或导致误判的浪型。开展浪型盲标试验。增加自选列表、连续收盘记录、到期核销、模型版本与回退。汇总个股和指数各自的覆盖、误差及数据中断情况。 | 在预定自选样本连续运行至少 20 个交易日，每个到期预测可追溯至原始报告，每个失败标的有状态。验证旧模型回退、快照重放和概率撤回。发布支持矩阵，逐项标明“可用于分析”“概率已验证”“证据不足”。结束本轮开发，转为按月监测和按缺陷维护。 |

## 发布概率和结束研究的门槛

1. **先锁协议，再看留出。** 记录证券名单来源、退市与缺失处理、数据版本、预测目标、分层和门槛。开发、校准、最终评估按时间分开，前一段的结果窗口不得跨入下一段。2023–2025 已查看的试跑样本列入开发证据。缺少未使用的历史区间时，使用首版起积累的前向记录。历史冻结回放和当时实际保存的预测分别汇报。[时间序列交叉验证](https://otexts.com/fpp3/toolbox.html#time-series-cross-validation)
2. **验证概率的含义及增益。** 用留出期 Brier 分数比较模型与训练期类别频率、只用过去 20 根收盘动量拟合的概率基线，另做移除波浪特征的对照。按共同决策日期做配对时间块抽样，保留同日不同标的之间的关联，时间块覆盖预测窗口。按预先固定的概率档比较预测均值和实际发生率，列出区间、样本量及拒绝预测比例。[概率校准与可靠性图](https://scikit-learn.org/stable/modules/calibration.html)
3. **预定可执行的放行条件。** 建议初值为相对两项基线的 Brier 改善均取正，配对差值的 95% 区间下界大于零。逐类检查准备展示的每个概率档，要求“预测均值与实际发生率之差”的 95% 区间全部落在 ±10 个百分点内。如果三类中任一项无法验证，该适用组的整组走势概率显示“未校准”。若加入波浪特征后的提升未获支持，单列价格基线结果，记录波浪特征的增益未获证实。盲标浪型另需在开发期锁定标注一致率底线、最低每类样本量和分歧处理规则。具体分档、最低样本量及门槛在查看留出结果前签入协议。
4. **给负结果一个终点。** 首轮锁定评估结束后，对仍缺样本的项目最多追加一轮预先规定的前向观察，以第 6 个月为本轮复核点。仍未达标即归档该事件或浪型的数值概率，保留条件剧本和验证报告。通过的概率按月复核覆盖和校准，超出锁定误差界限时暂停相应概率并保留历史版本。

**本期完成的定义**是用户能独立完成“输入代码 → 理解主备浪型 → 观察确认或失效 → 次日看变化 → 到期核对预测”的全过程。若概率验证失败，收盘分析工具仍可正式交付，概率目标明确记为未达成。国内范围为沪深个股和已接通的指数。美股在取得相应 Alpaca 行情 feed 权限后单独验收，指数分钟线按盘中需求和数据覆盖另排。浏览器图表沿用现有 HTML，独立 Web 服务在多用户或远程访问成为实际需求时再立项。[详细实现方案](IMPLEMENTATION_PLAN.md) · [验收记录](reviews/README.md)
