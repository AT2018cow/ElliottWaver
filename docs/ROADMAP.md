# EliotBot 开发路线图

更新于 2026-11-18，代码基线为 `98e287b`（`subwave-v6`）。下一阶段优先回答两个问题。沪深日线和周线收盘后，首选浪型有多稳定？报告给出的方向和目标有多少次得到后续行情支持？

收敛三角形启用子浪认证时采用 A 组。B 组用于实验对照，E 腿嵌套保留为 `PROVISIONAL`。同批 1,694 个决策时点，两组同报 8 个去重信号，零分歧。这个样本可以查回归，无法据此判断哪组预测更好。[规则决策与样本明细](reviews/2026-11-18-cn-triangle-classic-v6.md)

## 第一阶段 · 让每条历史判断都能复核

**下一项开发任务是实现通用离线评估入口。** 从现有逐前缀回放调用正式 `AnalysisService`，先用上证指数和贵州茅台各一份冻结日线快照跑日线、周线。三角形实验脚本继续作为已归档实验的复现入口。[现有回放](../src/eliotbot/evaluation/replay.py) · [现有事件标签](../src/eliotbot/evaluation/events.py)

| 交付物 | 验收条件 |
| --- | --- |
| 一份输入清单和一条离线命令 | 清单固定快照 ID、标的、周期、决策频率、缺口策略、子浪深度及配置。第二次运行能复现逐时点的候选、价格边界和事件日期。 |
| 逐时点决策表、事件表、汇总与文件校验清单 | 每个预定时点都有记录。分别列出数据不足、可分析但无信号、已发信号、无法定义事件、同根歧义和窗口未成熟。汇总可从明细重算，分母为零时输出空值。 |
| 正式入口一致性与复权回归 | 同一时点从完整快照和截断快照计算，已确认拐点、首选候选和价位一致。个股未来价格换算到决策日基准后再比较，周线先复权再聚合。现有两条茅台反例及五平台反例通过。 |

评估同时保留两种问题。报告中的目标带与结构失效线用来检验报告本身，只有阶段结束线时单列为事件未定义。方向比较另用预先约定的对称 ATR 边界，给引擎和简单基线相同的判定条件。

## 第二阶段 · 衡量沪深日线和周线的实际表现

第一阶段对账通过后，先在开发样本上试跑，再冻结评估协议。目标约 30 只沪深个股，按沪深主板、科创板、创业板分层，四个代表指数单列。记录名单来源、历史覆盖、退市或缺失样本。只能取得当前名单时，将结论限定在该固定样本。已用于选规则的 2023–2025 试跑数据归入开发证据。[原设计的 M7 评估要求](IMPLEMENTATION_PLAN.md#143-真实样本和统计协议)

1. **锁定比较办法。** 事前登记标的、全体决策时点、未查看的时间留出区间、结果窗口和判定门槛。开发样本的结果窗口应在留出期开始前结束。如果没有足够的未查看历史，就自锁定日起逐期保存当时的快照与决策，等窗口成熟再评估。
2. **回答两个问题。** 结构稳定性看同版数据和固定预热起点下的已确认拐点变更数、首选剧本切换率、确认延迟和 `UNCLEAR` 占比。方向表现以日线为主、周线单列。简单动量基线可取过去 20 根收盘涨跌，在相同 ATR 边界和窗口下先比较每百个可分析时点的先达目标次数，再在引擎已发信号的相同时点配对比较条件命中率，以区分覆盖率与方向判断的贡献。
3. **按结果决定。** 交付含分母、覆盖率、各浪型和市场分层、按时间块配对的差值区间及失败样例的报告。出现确认后拐点改写，先修因果性再重跑。样本稀少或差值区间跨零时保留“未分出优劣”。专门重启三角形 A/B 比较时沿用原协议的 50 个去重分歧及效应门槛。[三角形实验协议](reviews/2026-11-18-cn-triangle-experiment-protocol.md)

## 第三阶段 · 用证据决定引擎和产品投入

| 优先项 | 启动条件与交付标准 |
| --- | --- |
| 日常收盘报告 | 第一阶段已有可重算的相邻决策。用同一标的两次报告展示首选计数为何变化、哪些拐点已确认、下一条确认或失效条件是什么。终端、Markdown 和图表须与同一 JSON 候选及价格一致。 |
| 子浪认证补强 | 根据第二阶段统计，优先处理最常导致有价值候选证据缺失的一类。若选中 WXY 或嵌套 E 腿，先给出独立标注及涨跌镜像正反例，再验证真实前缀、误认证数和计算耗时，逐项决定是否升级认证。 |
| 概率校准 | 某个明确定义的事件积累足够成熟样本后，另设拟合段与独立验证段，比较 Brier 分数、基准事件率及分桶校准误差。验收前 `calibrated_event_probability` 保持 `null`。 |
| 美股与 Web | 有 Alpaca 账户及对应 feed 权限时，可并行补齐真实下载、离线复现和报告对账。Web 排在评估结果契约稳定后，首项验收为相同快照和配置下 API 与 CLI 的分析摘要一致。 |

本轮市场范围聚焦沪深个股和已有指数的日、周线，沿用此前排除北交所个股的约定。指数分钟线等到出现明确的盘中使用需求、且有可验证的历史覆盖时再排期。每阶段的结论放入 [验收记录](reviews/README.md)，原始输出保存在本地 `reports/`。
