# 多浪级引擎第二轮修复复验

本轮逐项处理 11 月 21 日复核发现的 12 个问题。分析结果的共享规则版本升级为 `ew-rules-v5`，增强规则版本升级为 `hierarchical-rules-v3`。增强模式通过 `--config config.advanced.example.yaml` 启用。 [上一轮复验](2026-11-20-wave-engine-repair.md)

| 项目 | 修复与复验 |
| --- | --- |
| 1. 递归认证选子浪 | 先比较子浪能证明的层数，再选择候选。细到粗、粗到细两种输入排列均找到同一个二层证明。反例还包含一个同尺度、端点合法但无法继续细分的更早匹配。 |
| 2. 浪 5 精确触线 | 上限用报价的十进制值计算，再转换成报告使用的浮点价格。上涨和下跌都验证触线有效、越一档失效，端点规则、影线规则和事件条件使用同一价格。 |
| 3. 父腿中的双重三浪 | 区间搜索尝试双锯齿和双重三浪，并按各自的内部组合认证。外层 `100/130/110/118` 的平台–锯齿–锯齿通过，两端都为锯齿的同价反例无法获证。 |
| 4. 自动换窗 | 只改变窗口下界，排除重复范围。宁德时代 `300750.SZ` 在 2026-11-05 的冻结决策得到三个不同窗口，均为 `OK`，一致返回 `SAME_COUNT`。 |
| 5. 日周历史证明深度 | 历史匹配与展示候选使用同一深度门槛。实际只有一层证明的历史日线锯齿，在请求深度 0、1、2 时分别为 `PROVISIONAL`、`VERIFIED`、`PROVISIONAL`。先处理展示候选，再向历史区间分配预算，回归覆盖首个历史区间耗尽其预算。 |
| 6. 拆股触发溯源 | 事件记录冻结输入中的 K 线 ID，观测值使用旧摘要发行时的价格坐标。2:1 拆股回归核对了两者。 |
| 7. 回放结构身份 | 评估直接取正式摘要首选卡的结构键。端点相同、亚型改变的用例记录为首选切换。 |
| 8. 回放比较模式 | 比较函数按当前摘要 schema 选择模式，评估和正式摘要调用同一函数。经典用例触发失效条件时，保留原有 `SAME_COUNT` 分类及触发条件。 |
| 9. 子浪证据更新 | 同一结构的树状态或已验证深度改变时，增强摘要标记 `EVIDENCE_CHANGED`，并记录前后证明层数。 |
| 10. 平台亚型边界 | 用规则数值容差判断 B、C 是否越界，顺势平台仍按最小越价幅度判定。已测上涨、下跌、恰好触线和跨一个 tick 的情况。 |
| 11. 主选切换率 | 按所有组的切换次数除以可比决策对数。覆盖空组、不同大小的组和总分母为零。 |
| 12. 穷举召回参照 | 独立参照使用单独的进行中端点。161 个合法参照含 111 个进行中候选，两种模式在充足预算下均召回全部 161 个。 |

证据位于 `tests/test_engine.py`、`tests/test_hierarchical_engine.py`、`tests/test_decision_comparison.py`、`tests/test_evaluation.py` 和 `tests/test_exhaustive_search.py`。冻结窗口复验使用 `25e8ab0aa16c69cd4a32b168bb36f05ed68075cf1fb4262555d918c9e3fa6cf9`。
