## EXT5-R01：有目标候选不连续时，报告错误显示连续范围

**优先级：P2；状态：已独立复现；待修正。**

位置：`src/elliottwaver/visualization/report_formatter.py:46` 附近，使用首尾下标构造 `S{first}-S{last}`。

触发条件：展示至少四个候选，存在 `EXCLUDED_STRUCTURE`，S1 没有目标，而有目标的候选为 S2、S4，S3 没有目标。这是格式器的独立构造输入；在本轮九组默认 Top-K=3 的真实报告中没有触发此模式，不声称已经影响那些报告。程序允许 `--top-k 4` 至 `20`。

实际文字：

```text
S1 当前无合法目标；S2-S4 提供条件性目标，可在图表中切换。
```

这会把没有目标的 S3 包含在“提供目标”的范围中。问题仅在新提示文字，JSON 中各候选的实际目标没有被修改。

建议修复：直接连接真实候选标签，如 `S2、S4`；或只对连续编号分组压缩，保留编号缺口。不要仅用首尾编号代表任意集合。

修复验收条件：

1. `[2, 4]` 显示 S2、S4，不能显示包含 S3 的范围。
2. `[2, 3]`、`[3]`、空集合均准确展示，不出现不存在的候选。
3. 保留既有权重分母说明和候选切换功能；添加检查具体提示内容的回归用例。现有新增 Markdown 测试只检查权重说明，未覆盖这段新提示。

## EXT5-R02：结果身份稳定性的文档描述错误

**优先级：P3；状态：已独立复现；待修正。**

位置：`docs/IMPLEMENTATION_STATUS.md:52`。新增段落声称“未涉及新目标、评分或过滤结构的样本结果身份保持不变”。

对比原始与 ext5 验证产物，600519 周线和 5 分钟线的业务字段确实相同：排除 `run_id`、`analyzed_at`、`engine_version`、`result_digest` 后没有字段差异。但是结果身份不同：

| 样本 | 原结果 ID 前缀 | 新结果 ID 前缀 |
| --- | --- | --- |
| 600519 周线 | `60325bfac02b` | `32d9101a2ad4` |
| 600519 5 分钟 | `20ec3c65b70a` | `444af8db22fd` |

原因：`service.py` 生成 `result_digest` 时保留了 `engine_version`。升级引擎标识后改变结果摘要是正确的版本隔离行为，不能为迎合文案而从摘要中排除引擎版本。九组新旧结果 ID 实际上全部不同。

建议修复文案为：“部分未受业务变更影响的样本，除引擎版本和运行标识外的业务内容保持一致；由于引擎版本参与摘要，所有样本重新生成结果 ID。”

修复验收条件：更正文案，保留引擎参与摘要的行为；用上述两个样本分别验证业务内容一致、引擎版本不同、结果摘要不同。

## EXT5-D01：第五浪评分属于新口径，应与原规格区分

**分类：设计差异与后续命名建议，不作为本轮新增算术缺陷。**

原 `DESIGN.md` 第五浪表规定：核心比例 1.0/0.618，次优 1.618 权重 0.7，sigma=0.10。新代码将更多比例升级为核心集合，sigma 改为 0.15，并与浪 5/浪 3 的另一集合取较大值。这不是简单补充遗漏比率，原有样本也会升分。

独立对照端点 `[100, 120, 112, 146, 137.976, 170.336]`，第五浪/浪 1 恰为 1.618：

| 指标 | 基线实现 | ext5 实现 |
| --- | ---: | ---: |
| 第五浪特征拟合 | 0.7 | 1.0 |
| 整体质量分 | 59.2969118913 | 62.2969118913 |
| 覆盖度 | 0.85 | 0.85 |

新引擎使用 `score-v2` 区分结果是正确的；但 `scoring.profile` 仍叫 `ew_score_v1`，原 DESIGN/实现方案仍保留旧比率表。建议后续同步命名和规格，明确这是 v2 的工程策略选择；如需保持 v1 配置可复现，再显式保留旧 profile。不能通过消除缺失证据或降低硬规则来“证明”新评分更好。

作为语义对照，EWI 的[等长指引](https://www.elliottwave.com/waveopedia/equality/)说明部分推动浪之间的比例关系，[Fibonacci 关系说明](https://www.elliottwave.com/waveopedia/fibonacci-relationships/)强调比例分析须以有效波浪解释为基础。这些资料不能直接验证本项目具体的高斯参数、两套关系取 max 的规则或收益效果；该结论属于本次验收对证据范围的判断。
