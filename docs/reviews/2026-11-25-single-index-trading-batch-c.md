# 单指数交易指导 C 批实施与复验

基线为完成联合修复的 A、B 批本地提交。C 批覆盖 TD-11、TD-12、TD-13。 [A、B 修复与复验](2026-11-24-single-index-ab-review-repair.md) · [C 批配置与入口](../USER_GUIDE.md#462-单指数的盘中确认与市场背景)

| 工作 | 实施及复验证据 |
| --- | --- |
| TD-11 市场背景 | 展示主指数的连续会话收益、日波动与历史分位、最近已观测隔夜跳空。固定参照需要同市场、同币种、同收益口径和共同连续交易日。用两份真实冻结快照在隔离缓存从 CLI 复算科创50相对沪深300的 20 会话收益差为 −4.025294 个百分点，区间为 2026-10-19 至 2026-11-16。开关背景前后，分析摘要、候选、点位、原观察窗及日线预案逐项相同。成分夹具分别检查 6/10 可比覆盖、4/6 上涨及权重覆盖。 |
| TD-12 盘中确认 | 15 分钟简报按本地可核验历史找到当时已发布的同指数日线预案。单独留存日线、60 分钟、15 分钟数据身份及到达时间。定向测试复现三根快照 K 线分别发生触价、收盘确认、回踩，原五根盘中事件仍在。另核对晚收到的父预案、缺失时段、同根破位、跨源两会话 OHLC 比对、同源同槽 1.5 倍量和提醒去重。 |
| TD-13 已知事件 | JSON 导入支持有版本的成分、收盘、事件及覆盖，按内容摘要留档。回放中按公告和首次接收时间确定能见度。10:05 公告、10:07 接收的事件直到 10:10 才进入该组探针，晚到修订不改变已冻结结果。30% 和 20% 的成分去重后为 50%。通过感恩节休市及下一会话开市时间核对日历。 |

## 代码审查修复

| 审查范围 | 回归证据 |
| --- | --- |
| 盘中策略与可见时点 | 固定日线发行的触发方法、回踩容差及两周期新鲜度。实时证据使用接收时间，延迟不能回填成准时触发。同根触发与失效保留歧义，独立提醒账本只接收有效触发。 |
| 父预案及回踩 | 按预案完整摘要和发行口径核对原报告。回顾性简报单独查询。同一预案支持延迟确认以及跨会话回踩。 |
| 事件窗口及提醒 | 仅使用仍有效的计划；事件与盘中追踪开关独立。收市后从下一会话计数，实际事件时间与窗口筛选一致。成分换仓分别报告窗口最高暴露和最低覆盖。未确认提醒独立于最近 50 份简报。 |
