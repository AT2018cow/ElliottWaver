# 路线图二轮评审修复复验

本轮按评审顺序覆盖 22 项问题。日常收盘分析、批量处理和研究发布分别验证。

| 评审项 | 修复及复验 |
| --- | --- |
| 1 美股拆股 | 用发行日前两条重叠日线核对相同原始 OHLC 与统一复权换算比例。日线、周线 2 比 1 拆股回归均保留发行坐标下的原结算结果。重叠不符时记录 `PRICE_BASIS_UNVERIFIED` 并保持待结算。历史条件触发使用同一换算。 |
| 2 强制模型批准时点 | 注册与离线评估共用留出期后的批准时间校验。早于或落在留出末日的日期被拒绝，合法批准日前强制计算仍标回顾性。 |
| 3 双人判读 | 导入、评分、训练均拒绝重复的案例与标注者组合，空白差异也无法冒充第二人。 |
| 4 校准分档 | 每档统计有样本的时间块。50 个观测、10 个日期集中在一块的反例无法生成置信区间，也无法获批。标的走势与浪型认可率两条路径均执行校验。 |
| 5 冻结回放标识 | HTML、Markdown 和终端显示模式与决策截止时刻。 |
| 6–8 自选批处理 | 数据不足和陈旧摘要返回 3，非法代码作为单条错误保留，继续处理其他代码。新目录并发初始化通过。 |
| 9 周线到期价 | 缺周内首日但有周五收盘时，收盘事件按周五结算。触价事件仍按完整周 OHLC 判断。 |
| 10 历史修订 | K 线和因子比较只覆盖前次决策的可见前缀。仅改未来 K 线与因子的反例不产生修订。 |
| 11 模型回退 | 最新文件内容为 `[]` 时，跳过该文件，继续使用较早的兼容批准模型。 |
| 12 评估合并 | 混合生成源码指纹失败。合法合并保留分片的生成指纹。 |
| 13 日周线对齐 | 两侧状态均为 `OK` 且各有明确方向时才显示一致或冲突。 |
| 14–18 盲标导出 | 校验业务身份、清单及文件，跳过篡改与暂存报告。纠正浪的字母端点可解析，JSON 和页面都使用中性编号。每个案例的涨跌选项独立。下载只包含已确认完成的案例，包括故意留空的判断。 |
| 19–20 核销批处理 | 同一业务摘要的多种格式只产生一组结果。路径不存在、无报告或有核销错误时返回非零，保留可输出的报告和错误明细。 |
| 21 概率展示 | 终端显示事件、作用域、期限、状态与数值。HTML、Markdown 和终端从实际概率状态生成说明。 |
| 22 候选遗漏 | 报告保留引擎 Top-K 之外的权重，并单列摘要额外省略的 Top-K 候选数量和权重。 |

本轮美股核销验证使用可控拆股回归；实际新旧快照需满足重叠价格换算条件。批准模型的可靠性分档必须包含至少两个有样本的时间块，缺该证据的既有模型应重新评估。盲标旧页面产生的全空行如无法与明确空选区分，重新导出案例并采集判断。

复验入口为 [定向回归](../../tests/test_review_followup.py) 及全量 `pytest`。原 [EW-R01–R09 修复复验](2026-11-19-roadmap-repair.md) 保留其样本外试跑结论。

## 复验结果

- 276 项全量测试通过。Ruff 检查、格式检查和补丁空白检查通过。
- 6 条三角形专项复验通过，包含两条茅台复权样例。
- 茅台、宁德时代、上证指数、沪深 300 的真实冻结快照均生成日周线摘要，与单独分析结果一致。Markdown 和 HTML 均显示冻结回放模式。
- 执行页面导出脚本，确认两个已完成案例分别保留上涨和下跌方向，明确送出的空选案例保留，未完成案例省略。
