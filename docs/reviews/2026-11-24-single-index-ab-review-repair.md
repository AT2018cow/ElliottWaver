# 单指数 A、B 批联合审查修复

| 审查项 | 修复与验证 |
| --- | --- |
| 原始指数点位跨快照 | 同指数、同源、同调整口径的原始点位可以比较，继续核对发行信号 K 线。更换 feed、变更复权口径或修订原始信号仍有明确状态。 |
| 缺口晚到 | 累计完整前缀的最晚可用时间。早一会话晚到十秒时，后一会话的收盘无法在截止前激活。 |
| 回执写入跨窗口 | 报告在回执写完并通过时钟检查后开放读取。注入慢写时可见性检查拒绝该目录，过期发布撤回。 |
| LIVE 原请求重试 | 冻结请求单独索引，使用原报告与回执。因果历史查询继续使用原截止语义。 |
| 盘中过期格点 | 更晚区间已经可用时，旧格点记为 `SUPERSEDED`，保留决策网格及 ID，评分排除该行；前向重算核对分析的末根时间。 |
| 拐点确认身份 | ZigZag 记录实际确认 K 线身份。两根行情共用可用时间时仍取真正的确认价。 |
| 结算证据 | 已登记观测所需的会话、时刻和已知 bar ID 必须在结算快照中可查。旧快照会明确被拒绝。 |
| 目标歧义上下界 | 触发和失效同根与持有后目标和退出同根分别统计。触发同根的变动不计作激活后可能达到的目标。 |
| 模型适用范围 | 展示注册表批准时同时核对研究行的标的、市场、feed、调整、卡片及版本范围。 |
| 测试回执 | 同时校验包源码、测试文件、共享夹具、脚本和配置摘要。旧回执缺少测试输入摘要时显示未核验。 |

定向验证通过 47 项，包含审查反例。最终全量回归 639 项、Ruff 和暂存差异检查均通过。使用注入时钟、冻结样本与模拟接口。实时连续发行和实际成交仍由对应前向批次验收。
