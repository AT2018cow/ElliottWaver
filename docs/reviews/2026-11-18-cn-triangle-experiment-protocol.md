# A 股三角形子浪规则对照实验

交给 DeepSeek 执行。实验回答两个问题。第一，两套实现各自符合哪一组波浪规则。第二，在沪深市场的日线和周线上，哪一套规则选出的候选更有用。行情结果用于评价筛选规则的表现，结构是否符合定义由规则和子浪证据判定。

## 分歧与已有证据

| 分歧 | DeepSeek 本次实现 | Codex 验收采用的口径 |
| --- | --- | --- |
| `T-R01` 平台形 | 三角形五条腿各自允许锯齿、平台或双锯齿 `WXY`。五条平台可以全获认证。 | Frost 与 Prechter 对收敛三角形要求至少四腿各为锯齿或锯齿组合，复杂腿最多一条。应检查五腿组合，再决定整体认证和评分。 |
| `T-R02` 嵌套三角形 | 每条腿都排除三角形子模板。 | EWI 记录过少见的子三角形，通常在 E 腿。程序可先支持 E 腿候选，端点、方向和子结构证据齐全后再认证。 |

原著规则与图例见 [Frost 与 Prechter 的收敛三角形章](https://studylib.net/doc/28544323/elliott-wave-principle--key-to-market-behavior)和 [EWI 的九浪三角形示例](https://www.elliottwave.com/waveopedia/triangles/)。原著提到的嵌套例外以收敛或平边子三角形为例。先前代码反例只验证 E 腿的许可表和端点关系，完整子结构仍待核对。单条平台与四条锯齿并存的混合情况可保留给人工复核。

此前涨跌两向的五平台反例均从 0 分升到满额 15 分，五锯齿对照均通过。另一个涨跌两向的反例中，现有代码对 E 腿的精确父级匹配从 `VERIFIED` 变为 `UNKNOWN`。21 组冻结快照在两版上的结果摘要完全一致，说明固定样本未区分两版。复现脚本、源码指纹和观察结果见[独立验收记录](2026-11-18-triangle-children-acceptance.md)。

## 第一步　复现与结构验收

先运行已有脚本，保留它们的原始输出。第一条在受验版本预期退出 1，报告两个反例失败及一个正向对照通过。第二条预期退出 0。比较原验收记录中的两份源码指纹。若工作区已有后续修改，记录新指纹和差异，并用隔离目录复现历史版本。

```bash
.venv/bin/python scripts/acceptance_triangle_children_20261118.py \
  --output reports/cn-triangle-experiment/preflight-triangle.json
.venv/bin/python scripts/acceptance_parent_subwave_20261118.py \
  --frozen --output reports/cn-triangle-experiment/preflight-p3.json
```

再做下列最小对照。每个用例保留父子端点、各腿可选模板、命中的硬规则、最终状态和实际子浪分，并检查涨跌镜像。

| 场景 | 经典口径的预期 |
| --- | --- |
| 五条已确认锯齿 | 通过整组检查。 |
| 五条仅通过平台硬规则的腿 | 整体未通过，子浪分低于满额 15 分。 |
| 四条已验证锯齿加一条有结构证据的 `WXY` | 通过实验支持的整组检查。若当前搜索只得到 `WXY` 端点，标记证据不足。 |
| 两条已验证的复杂腿 | 触发收敛三角形的复杂腿数量约束，即使两个子模板分别成立。 |
| 四条锯齿加 E 腿候选子三角形 | 精确匹配且形态有证据时进入认证。只有端点匹配时标记待确认。另测方向不符、跨父腿和未确认端点。 |
| 普通推动第 3 浪的楔形反例、深证成指三角形 C 腿反例 | 维持 P3-R01、P3-R02 修复行为。 |

嵌套试验先使用官方图例或独立标注的收敛／平边子三角形验证位置和内部规则，再接实际行情。当前引擎部分模型要求腿两端包住所有内部影线，某些嵌套因此无法表示。记录这类案例及触发的规则。价格回放分支保持同一套端点与影线检查。若为支持嵌套另改父模板几何，作为新版本单独试验。

## 第二步　冻结 A 股样本与可比较版本

主实验只比较 `T-R01` 的整组认证政策。为两组供给同一批确认拐点和各腿的同一套候选证据。保留匹配的备选子模板，经典组要检查是否存在满足整组约束的组合。使用一样的候选排序规则和固定搜索上限。

| 组别 | 变化点 |
| --- | --- |
| A 经典组 | 至少四腿有已验证的锯齿族结构，复杂腿最多一条。纳入自动认证的模板限于本试验有证据的锯齿、双锯齿和嵌套。完成阶段所有腿均需有支持证据。 |
| B 宽松组 | 按 DeepSeek 的逐腿许可复现。锯齿、平台、`WXY` 可进入候选，各腿满足其子模板约束即可累计拟合，不设至少四条锯齿族结构的整组门槛。 |

主实验对两组统一关闭嵌套自动认证。现有细拐点认证器主要覆盖普通推动、楔形、锯齿和平台。两组只有 `WXY` 端点而无内部证据时统一记为待确认，并报告数量。若补充 `WXY` 检测，两组必须使用同一检测器，且需在留出前验证并冻结。另对 `T-R02` 做一组单变量对照，固定 A 的评分政策，只切换 E 腿嵌套关联的资格，按[父级关联与评分的调用路径](../../src/elliottwaver/service.py)核实该切换是否影响实际输出。若只改变父级标签，比较关联覆盖率和标注一致性。

- **样本。** 指数用 `000001.SH`、`000300.SH`、`399001.SZ`、`399006.SZ`。个股按沪主板、深主板、科创板、创业板分层，每层预定 10–20 只。用历史可得的名单或证券主表抽样，按规则保留后续退市样本。只有今天的名单时，把个股结论标为固定样本分析并披露幸存者偏差。指数、个股与各板块分列。
- **时间。** 建议原始数据至少覆盖 2015-01-01 至 2026-03-31。2019–2022 用于实现和检查，2023–2025 为一次性历史留出，2026 年一季度仅用于补足结果窗口。日线每周最后一个交易日作决策，周线取已结束且可用的整周。完整前置历史不足的时点单列。正式运行前固定实际起止、标的、预计样本量和排除原因。可先用一个指数和一只个股做小样本运行。
- **唯一改动。** 两组冻结同一份源快照、周期、日历、复权、锚点、ZigZag、候选搜索预算、`max_subwave_depth=1`、评分权重、Top-K 和缺口策略。缺口严格模式为主，显式容忍缺口作为敏感性分析。涨跌停分层仅用当时有效的制度与原始行情识别。缺乏可靠标签时标记未知。[创业板价格限制研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0287548)

## 第三步　按历史时点评价

复用 [逐前缀回放](../../src/elliottwaver/evaluation/replay.py)。对决策时点 `t` 只使用 `usable_at <= t` 的已完成 K 线及已确认拐点。周线沿用完整交易周聚合。个股特征在 `t` 的复权基准计算，未来结果用同一基准的价格坐标。未来复权因子只能进入结果计算，例如用 `F(s)/F(t)` 将未来 `s` 的原始日线映射到 `t` 的基准后再聚周线。记录 `FROZEN_DATA_REPLAY`、数据修订和证券名单来源。包含未来 K 线的输入与截断输入在同一 `t` 复算应给出相同决策。

**决策单位。** 按共同的 `标的 × 周期 × 时点` 网格比较。每组在自身达标 Top-K 中取第一个已完成且通过本组认证政策的收敛三角形。用[现有硬规则](../../src/elliottwaver/engine/rules.py)区分收敛和扩散，保留两组原始认证字段。没有候选时记为无信号。同一组六个粗尺度端点组成的形态，按标的、周期、方向和端点原始 bar ID 生成稳定键，跨时点只记首次信号。两组以相同的时点输入质量规则确定主分母，搜索截断和输入不足各自单列。记录双方都报、仅 A 报、仅 B 报、双方均未报，以及两边均报但形态或方向不同的数量。

**共同结果。** 当前 [投影器](../../src/elliottwaver/engine/projector.py#L45)对完成态通常输出 `STAGE_EXIT`，而 [事件标签器](../../src/elliottwaver/evaluation/events.py#L27)要求 `INVALIDATION`。直接组合两者会得到 `UNDEFINED_EVENT`。本实验单独固定对称边界，以 `t` 的收盘价为中心，上下各一倍当时的 ATR(14)。方向统一取与 `D→E` 相反的方向，作为本次预注册的价格假设。日线看随后 20 个交易日，周线看随后 8 个完整交易周，并按周历核对缺失周。决策当根在结果窗口之外。

先触及预测方向边界计 `TARGET_FIRST`，先触及反向边界计 `ADVERSE_FIRST`。跳空越过边界在首根能观察到的 K 线记触及。两侧同根触及计 `AMBIGUOUS_SAME_BAR`。窗口内始终未触及计 `EXPIRED`，缺失结果和样本尾部未成熟分别计 `INCOMPLETE_DATA`、`RIGHT_CENSORED`。同方向、同时点的信号在两组使用相同边界。附表可注明实际结构失效条件的结果，但独立报告其适用样本数。两种结果都是价格标签。

对 `T-R02` 从两组选出的和未匹配的真实 E 腿取固定样本，隐藏版本结果和后续行情，由独立标注者核对端点、子型及内部证据，允许「成立」「不成立」「无法判定」。报告不同标注者的一致率和争议样本。若只能完成单人标注，按个案复核呈现。

## 第四步　判定与交付

主结果先看**留出期日线**。周线、指数和各板块分别给出。至少报告信号覆盖率、每 100 个共同决策时点的 `TARGET_FIRST` 次数，以及结果明确且窗口成熟的已发信号中 `TARGET_FIRST / (TARGET_FIRST + ADVERSE_FIRST + EXPIRED)`。列全分母及无信号、同根歧义、缺失、截尾计数。歧义做全成功和全失败两种边界分析。重点单列版本意见不同的时点，避免大量相同结果掩盖差异。置信区间按连续时间块对共同日期配对重抽样，同时保留同一日期各标的的关联。建议日线块覆盖至少 20 个交易日，周线块至少 8 周。

建议在读留出结果前锁定门槛。一个可执行的起点是至少 50 个去重后的分歧信号，主要指标至少增加每百个决策时点 1 个先达目标，配对差值 95% 置信区间下界大于零，同时条件命中率差值的下界不低于 −3 个百分点。这些是实验判定参数，可在开发期按样本量修订并留痕。两个方向使用同一标准。

- 经典组满足结构规则，且留出表现占优时，将其作为 A 股默认口径。结构通过而结果没有可辨差异时，仍可作为标准数浪默认口径，预测优劣保留待定。
- 宽松组留出期达到预设门槛时，记录它作为 A 股候选筛选变体的用途。经典认证标签仍依据已采纳的理论规则。
- 分歧太少、区间跨门槛或结果依赖个别板块时，结论写「本实验未分出优劣」，附分歧样本和实际区间。预先约定的数据调整和主实验结束后的新增试验分别记录版本。

交付 `protocol.json`、`manifest.json`、逐时点对照与事件表、分歧个案、嵌套标注表、可重跑命令以及简短结论。清单须保留代码和协议指纹、A/B 的不同规则版本、快照 ID 与哈希、有效参数、时点和标的名单、排除原因及产物校验和。运行结果放在 `reports/cn-triangle-experiment/`，结论可链接到本页。实验输出评估的是价格边界结果和结构一致性，交易可执行性与收益属于后续研究。

实验结果见 [A 股三角形子浪规则对照实验结果](2026-11-18-cn-triangle-experiment-results.md)。
