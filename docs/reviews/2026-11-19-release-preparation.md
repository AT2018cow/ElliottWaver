# 日用版与指数概率候选验收

## 日用版

收盘摘要的主周期候选显示规则状态。终端给出通过、违反和证据不足的数量，网页可展开查看详情，Markdown 列明实测值及判定边界。旧报告的业务摘要和 JSON 契约保持兼容。安装包在隔离环境用茅台日线和沪深 300 周线冻结快照复验，两份报告均为 `OK`。历史可查询，行情概率状态为 `UNCALIBRATED`。

独立端点复核使用先前的 46 个盲标留出案例，另从训练、校准批次各预取 5 个具备四个或六个端点的案例。用校验后的快照逐段复算，18 个案例至少通过一个端点模板，38 个保留待定。结果单列端点证据和不确定项。完整规则结果位于本地 `reports/cn-probability-release-2026/next/rule-review-56.json`。

端点复核可以用于日用版。复杂模板的内部划分仍按子浪证据表达。独立人工认可概率是另一个研究指标。

全量测试 284 项通过，Ruff 和差异检查通过。经验证的本地 wheel 和校验文件位于 `reports/cn-probability-release-2026/next/wheel/`。

## 概率候选

指数 20 日目标先达用 2023–2025 的三个时间折选择了带截距的校准，然后冻结参数和三条基线。汇总 log loss 从 0.35563 降至 0.34875，Brier 从 0.10556 变为 0.10572。开发期比较用于选型。

将复验数据中 6,408 条 2026 事件的结果改写后，三个开发折的指标、选型、拟合参数和基线完全一致。直接把已看过的 2026 评估交给新评分入口时，命令拒绝评分。普通训练器重跑原冻结评估，个股与指数的模型 ID 和事件指标均与修改前一致。

合成验收覆盖新留出证据不足时拒绝注册，也覆盖事件通过时生成标准模型和仅对已验证指数加载。真实概率发布仍需新留出达到原有的基线、校准和覆盖率条件。[冻结参数与前向验收](../protocols/cn-index-target-forward.md)
