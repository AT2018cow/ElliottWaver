# ElliottWaver 产品路线图

目标是输入一只个股或一个指数，得到按艾略特波浪规则生成、能逐项复核的收盘分析。报告说明起浪点、主选与备选、各自的规则依据，以及哪些价位会改变判断。日用首版覆盖沪深个股及已接入的沪深京指数，以规则正确、数据可靠和报告可读为发布条件。事件概率是独立研究项。

## 现在就能使用

在仓库根目录运行。`brief` 用中文显示主备浪型、短期目标区和改变判断的条件。下列命令只保存 JSON 文件，同时保留终端文字。省略 `--format json` 时也会生成 Markdown 与 HTML。已接通的指数支持日线和周线。

```bash
.venv/bin/elliottwaver analyze 600519
.venv/bin/elliottwaver analyze 000300.SH --timeframe 1w
.venv/bin/elliottwaver brief 600519 --format json
.venv/bin/elliottwaver brief 000300.SH --timeframe 1w --format json
```

`brief` 提供自动选窗、主备浪型、条件价和数据警告。默认日线附周线背景，长跨度请求自动选周线。可用 `history` 查旧摘要，`watchlist` 跑自选，`settle` 核对到期结果。阅读候选时同时看质量分、证据覆盖和确认／失效条件。当前没有获批的真实行情概率模型。[中文使用手册](USER_GUIDE.md) · [实现与验收状态](IMPLEMENTATION_STATUS.md)

## 日用首版的验收优先级

1. **规则符合约定。** 按浪型和阶段列出启用的硬规则、评分指南和证据要求。每条硬规则用手算正例、反例和边界值验证，覆盖涨跌镜像、等价位与影线。存在流派分歧时记录采用的口径和适用条件。
2. **端点和条件可复核。** 同一数据口径下，截取决策日的行情应复现当时的已确认端点、浪型和条件价。区分已确认与进行中端点，以及确认、硬失效和阶段退出。目标区给出计算依据。数据或结构证据不足时给出明确状态。
3. **实际入口可日用。** 用沪深个股和已接入指数的冻结日线、周线走完分析、图表和历史查询。对照单周期结果，确认报告里的每个结论都能回到相同的候选、K 线和规则。真实案例覆盖多解、缺口、跳空、失效与重新数浪。

历史回放用于检查决策时可以使用的证据，以及后续如何触发确认、退出或失效。规则变更以规范、可复算反例和回归结果为依据。以上三项达到验收标准即可收口日用版。[工程复验方法](WAVE_ANALYSIS_DESIGN.md#规则正确性验收)

| B　周线背景与换窗复核 | 一次读取日线数据，同时看最近完整周和另一合理起点下的结果。**首版已接入 `brief`：周线背景、跨周期对齐、换窗复核。** | 日周结果分别等于各自单独运行的结果。换窗后方向反转、停牌缺口、未完成周、锁定锚点和短历史都有明确输出。 |
| C　逐次判断与历史查询 | 随时调出原报告，看首选为何变化、此前哪些条件已经触发。**首版已实现：`elliottwaver history`、SQLite 索引、`previous` 对比、重叠 K 线/因子修订检测、`CONFIG_CHANGED` 配置变化和 `NOT_COMPARABLE` 数据口径变化。** | 可区分新 K 线、历史数据修订和配置变化。重复运行无重复判断，事后回放与当时实际记录分开。 |
| D　事件与离线评估 | 对每个标的、时点和候选核对实际结果。**首版已实现：`scripts/evaluate_briefs.py`，支持日线/周线网格、按标的/资产类型/周期/浪型/期限分解，以及已确认拐点改写数、极值至确认 K 线数、相邻主选切换率、预测覆盖、确认延迟和搜索截断。** | 固定样本与正式入口结果一致。逐项还原分母、预测覆盖、首选切换、确认延迟、目标和失效次序、短期收盘方向。 |
| E　短期走势与候选确认概率研究 | 研究固定期限的收盘分布、确认先达和目标先达。已实现训练、校准、对照、冻结协议和模型注册。 | 独立于日用版验收。各事件按品种、周期、期限和留出证据审批。日用报告明确标识概率状态。[留出重算](reviews/2026-11-20-cn-index-probability-recheck.md) |
| F　浪型复核与结构补强 | 日用版逐条显示规则证据。可对冻结盲标案例用 AI 编写的规则复核器复算端点、影线和形态边界。证据不足保留待定。 | 逐条判断可以回到行情核对，端点与子浪证据各有状态。真实人工认可概率和一致性留作研究。[日用版验收](reviews/2026-11-19-release-preparation.md) |
| G　自选复盘与稳定运行 | 批量看自选个股和指数，查原判断、到期结果及所用模型。**首版已实现：`elliottwaver watchlist`（有限重试、有界并发、模型注册表回退）、`elliottwaver settle`（增量核销、修订版本、最初观察保留）和 `elliottwaver support-matrix`（资产/周期/事件/模型/测试/原因）。** | 单个失败不丢其他结果。重试、并发、缺数据、模型撤回与回退均通过。每个支持的功能有一份可复现的验收记录。 |

## 多浪级引擎增强

`v0.3.0` 通过 `hierarchical_v1` 配置启用逐腿结构树、日周关系、浪型亚型和多窗口复核，日用默认采用 `classic_v4`。独立复验已覆盖递归认证、历史日周关联、浪 5 精确触线和回放。11 月 20 日按完整摘要逐次计时，增强模式在沪深和美股的 p95 分别为原 `0.2.1` 的 3.34 倍和 2.34 倍。这是 `v0.3.0` 发布前的测量，下一版从发布标签重测。 [独立性能复验](reviews/2026-11-20-wave-engine-repair.md#摘要延迟) · [规则及回放复验](reviews/2026-11-21-wave-engine-followup-repair.md) · [实施计划](WAVE_ENGINE_IMPLEMENTATION_PLAN.md)

### 增强模式的性能与证据展示

目标是让深度 1 的增强摘要适合每天查看沪深和美股自选，并能快速追溯每个结论的规则、K 线和证据状态。

| 优先项 | 要做的工作 | 完成标准 |
| --- | --- | --- |
| 1. 测量并降低摘要耗时 | 用 `v0.3.0` 固定基线，分开计时主窗口、换窗、子浪搜索和日周关联。优先检查同一批 K 线在多窗间重复计算的指标和拐点，再根据实测热点优化历史父腿搜索。 | 每市场至少 30 个冻结决策，预热后各测 3 轮，公布完整摘要的 p50/p95、预算截断率和首选认证覆盖。两市场的 p95 均有可复测的改善。充足预算下合法候选召回和关键规则正反例保持通过。 |
| 2. 补齐增强模式的逐腿证据 | `v0.5.0` 已把主备浪型、短期条件和目标提到首屏，核对依据显示已验证层数与检查深度。后续可补充首个待确认浪腿、预算耗尽位置及主选变化所对应的证据。 | 进行中、缺交易日、价格口径不可比、预算截断各有可区分的表现。终端、HTML 和 JSON 的状态一致，能回到原 K 线或对应规则。 |
| 3. 复验日用全流程 | 选沪深个股和指数、美股个股和 ETF，使用同一冻结基线核对 `brief`、`watchlist`、历史报告与结算。保留拆股、缺口、未完成周和跨窗口分歧的独立用例。 | 单标的与批量分析结论一致。旧摘要和条件可验证。完整快照与物理前缀一致，触发可定位到源 K 线。 |

增强模式默认切换另按既有验收门槛决定。沪深与美股的完整摘要 p95 均达到 `0.2.1` 基线的两倍以内，同时通过规则、因果和兼容性复验，才评估默认切换。 [默认切换条件](WAVE_ENGINE_IMPLEMENTATION_PLAN.md#独立验收门槛)
