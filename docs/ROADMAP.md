# EliotBot 产品路线图

目标是输入一只个股或一个指数，得到可复查的收盘判断：从哪里开始数浪，主选和备选各是什么，哪些价位会让判断改变，以及同类判断过去有多可靠。国内范围为沪深个股及已接入的沪深京指数。日常分析、效果评估和概率发布各自验收。

## 现在就能使用

在仓库根目录运行。默认生成终端摘要、Markdown 和可离线打开的 HTML 图表。当前每次选一个主周期，引擎自动选择背景锚点，给出可辨认的浪型、相对权重和条件价。已接通的指数支持日线和周线。

```bash
.venv/bin/eliot analyze 600519
.venv/bin/eliot analyze 000300.SH --timeframe 1w
```

一个候选权重很高，也可能只有很少的结构证据。阅读时同时看质量分、证据覆盖和确认／失效条件。现有统计概率字段为空。[中文使用手册](USER_GUIDE.md) · [实现与验收状态](IMPLEMENTATION_STATUS.md)

## 工作清单

编号与[给 DeepSeek 的实施设计](WAVE_ANALYSIS_DESIGN.md)一致。**A 可以独立交付给用户。** B、C 分别让报告能解释跨周期分歧、能和上次判断对照。D 至 F 负责产生可验证的概率证据。

| 工作 | 用户获得什么 | 完成标准 |
| --- | --- | --- |
| A　收盘摘要与自动选窗 | 输入代码，在一页中看到分析范围、起点理由、主选、备选、各自的确认与失效条件及目标区。 | 两只沪深个股和两个指数通过。每条结论可回到同一张图和同一个候选。单候选、无候选、历史不足、无目标、没有概率模型均有可读结果。 |
| B　周线背景与换窗复核 | 一次读取日线数据，同时看最近完整周和另一合理起点下的结果。 | 日周结果分别等于各自单独运行的结果。换窗后方向反转、停牌缺口、未完成周、锁定锚点和短历史都有明确输出。 |
| C　逐次判断与历史查询 | 随时调出原报告，看首选为何变化、此前哪些条件已经触发。 | 可区分新 K 线、历史数据修订和配置变化。重复运行无重复判断，事后回放与当时实际记录分开。 |
| D　事件与离线评估 | 对每个标的、时点和候选核对实际结果。 | 固定样本与正式入口结果一致。逐项还原分母、预测覆盖、首选切换、确认延迟、目标和失效次序、短期收盘方向。 |
| E　短期走势与候选确认概率 | 分别回答“5／20 个交易日后收盘在上方、区间内、下方的概率”和“该候选在有效期内先得到确认的概率”。 | 事件、品种、期限分别通过独立留出检验。显示样本量、适用范围与误差。未获支持的项目交付验证结论，收盘摘要继续可用。 |
| F　浪型标注与结构补强 | 了解同一浪级下不同浪型得到独立判读支持的程度，降低常见误认证。 | 盲标可多选、可弃权，可重算一致率。只发布有一致性和校准证据的类别。每项引擎改动有独立正反例和冻结行情回归。 |
| G　自选复盘与稳定运行 | 批量看自选个股和指数，查原判断、到期结果及所用模型。 | 单个失败不丢其他结果。重试、并发、缺数据、模型撤回与回退均通过。每个支持的功能有一份可复现的验收记录。 |

## 做到什么状态可以收口

日常工具以“输入代码 → 读主备浪型 → 查看条件 → 对照下一次收盘 → 取回原报告”为完成标准。概率按事件单列为已验证、证据不足或未通过。用尽事先锁定的样本仍未达标时归档该项结果。仅在有独立的新数据或明确规则修订时重开。三角形采用经典 A 组，B 组保留作研究对照。[规则决策](reviews/2026-11-18-cn-triangle-classic-v6.md)

美股沿用 Alpaca 单周期入口，联合报告和概率按其实际 feed 单独验收。指数分钟线、独立 Web 服务按新增使用需求另行立项。每项完成后将实测结果登记到[验收记录](reviews/README.md)。
