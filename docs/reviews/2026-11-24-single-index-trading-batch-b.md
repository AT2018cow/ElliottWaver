| TD-07 | 原预案沿用已发行的点位。短暂换浪待下一根完整日线确认，稳定更换时保留原 ID 和关联版本。硬失效终止原预案。A→B→A 及连续 B 分别复验，首次发行 bar 被修订时保留已观察触发和原 K 线 ID。结算研究给出可比相邻对数、切换率和取消次数。 |

| TD-09 | 方向归一化后分别记录目标区、参考点、ATR、进入/越过状态。2、5、10、20、30 会话研究统计提供在险人数、累计发生率、删失与歧义敏感性。独立校验三个样本的第 2、5 日目标累计发生率为 1/3、2/3。第三例删失时，第 5 日为 1/3。 |
| TD-10 | 记录极值、引擎确认和确认所需行情完全可用的时刻，保存当时价格及 ATR。下一可观察指数价单独标时。手算 104→106、ATR=2、目标 110，已走 1 ATR、剩余 2 ATR。研究报告用相同拐点标识连接先前开发中观察和后续确认，并计算价差及等待期间可观察的目标/失效。 |
